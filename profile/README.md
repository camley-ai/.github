# Camley

Fund administration, rebuilt around agents.

Fund admin runs on documents and reconciliation — capital calls, NAV packs,
LP statements, allocations. Most of it is still done by hand. We're building
the platform that does it properly: [camley.ai](https://camley.ai).

## What we ship

* **[app.camley.ai](https://app.camley.ai)** — the product. Fund admin for
  managers and their LPs.
* An agentic backend that reads the documents, does the work, and shows you
  where every number came from.

Our code lives in private repos, so there isn't much to see here yet. When we
open source something, it'll show up on this page.
